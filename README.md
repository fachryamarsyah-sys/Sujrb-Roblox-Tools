#  Sujrb Roblox Tool

**CREATOR IS NOT RESPONSIBLE IF THE TOOL HAS BEEN USED AGAINST OTHER PEOPLE WITHOTU THEIR CONSENT** 

An **open-source** tool under the **AGPL license** that streamlines Roblox account management, allowing you to automate tasks, manage your account, groups, and games, and perform bulk actions. Whether you're managing a single account or multiple cookies, this tool has you covered!

##  **Quick Setup**  
1. **Configure `settings.json`**:
   - Paste your Roblox account cookie into the designated field.
   - If using someone else’s cookie, set `Bypass` to `true`.

2. **Install Dependencies**:
   - Run `pip install -r requirements.txt` to install required packages.

3. **Run the Tool**:
   - Execute `main.py` to get started.

##  **Features** 

###  **Account Info**  
- **View Key Details** of your Roblox account:
  - Cookie Information
  - Birthday, Gender, Country
  - Robux Balance
  - Last Known Location
  - PIN, Email & Age Verification Status

###  **Mass Deletion**  
- Mass Delete:
  - **Mass Group Leaving**
  - **Mass Unfavoriting of Games**
  - **Mass Unfollowing & Unfriending**
  - **Mass Deleting T-Shirts & Outfits**
  - **Off-Sale Game Passes Management**
  - **Mass Creation of Outfits & Game Passes**

###  **Modify Your Account**  
 - **Pin Cracker** (Bypass pin restrictions)
- **Manage and Modify Account:**
  - Change **Account Name**, **Description**, and **Avatar**  
  - **Randomize Avatar** appearance for a fresh look  
  - Modify **Game Names** and **Descriptions**

###  **Modify Group & Game **  
- Manage groups and games:
  - **Message All Users in Groups**
  - **Leave Groups Quickly**
  - **Unfriend Everyone**
  - **Upload & Steal Group Clothes**
  - **Check Group IDs**


###  **Miscellaneous Features**  
- **Extra functionalities**:
  - **Spam User Inbox**  
  - **Auto Ally with Groups**
  - **Nuke Account/Cookie** (Be careful – this is irreversible!)
  - **Unregion Lock Cookie** (Bypass regional restrictions)
